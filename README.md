Predicting Hotel Cancellations to Support Business Decision-Making

Project Overview

This Capstone project aims to analyse historical hotel booking data to identify patterns related to cancellations and explore how data analytics can help predict cancellation risk.

Project Objectives

Analyse historical hotel booking data.

Identify booking characteristics linked to cancellations.

Explore classification models to predict cancellation risk.

Investigate how the findings could support hotel occupancy planning and revenue management.

Dataset

The project will use the publicly available Hotel Booking Demand dataset, which contains booking records from a city hotel and a resort hotel in Portugal.

Tools

Jupyter Notebook

GitHub

Project Status

This project is currently at the proposal stage. Data analysis and predictive modelling will be developed as the project progresses.
